# Release Notes

## 0.1.0-beta - 2026-09-11

First public beta package set.

- macOS Intel ZIP
- macOS Apple Silicon ZIP
- Windows x64 installer
- Pic2Pet v2 distribution website support

Known notes:

- Apps are unsigned/not notarized in this beta.
- Apple Silicon and Windows builds should be verified on real target machines.
- In-app auto-update requires signed updater artifacts in a later release.
